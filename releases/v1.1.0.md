# Release v1.1.0 — Notificações completas

- Data: 26 de agosto de 2026
- Estado: publicada e validada no ambiente público
- Escopo: BFF, frontend e infraestrutura

## Entregas

- preferências globais de e-mail e push;
- preferências por evento para sistema, push e e-mail;
- catálogo de 24 eventos sociais, financeiros e de dívidas;
- cadastro, listagem e remoção de dispositivos Web Push;
- service worker Angular com navegação ao clicar na notificação;
- remoção automática de subscriptions expiradas;
- e-mail transacional preservado atrás do BFF;
- central in-app persistente com sincronização por SignalR;
- configuração VAPID separada por ambiente;
- suporte arquitetural futuro a APNs e FCM sem quebrar BFF-first.

## Validação pública

O cenário ponta a ponta foi confirmado num Edge real no Windows:

1. permissão do navegador concedida;
2. dispositivo persistido e exibido na conta;
3. solicitação de amizade criada por outra conta;
4. evento exibido na central interna;
5. serviço de push aceitou a entrega com HTTP `201`;
6. notificação recebida no sistema operacional.

Também foram validados build, testes automatizados, contrato OpenAPI, imagens do
BFF, deploy no ZimaOS e produção da Vercel.

## Promoções

- BFF: PR de release `#10`;
- frontend: PR de release `#9`;
- infraestrutura: PR de release `#12`.

Finance Service e Debt Service não precisaram de mudança para esta release. Os
eventos continuam sendo consolidados pelo BFF a partir dos contratos existentes.

## Limitações conhecidas

- alertas externos da infraestrutura continuam adiados;
- os backups ainda ficam no mesmo host físico;
- push nativo de iOS e Android dependerá de adaptadores APNs/FCM;
- permissões e entrega dependem das políticas do navegador e sistema operacional.
